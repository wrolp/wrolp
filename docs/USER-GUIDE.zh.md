## 1. 快速开始

### 安装

- Windows：下载发布版的 `.msi` 安装包双击安装（当前打包目标仅 MSI）。
- Linux / macOS：可从源码构建，参见 `README.zh.md` 的「构建」一节。

### 首次启动

1. 启动后进入主界面：左侧为连接列表，右侧为终端区，底部为会话/命令集/分析面板，顶部为自定义标题栏。
2. 左侧点击 **+** 添加第一个 SSH 连接（详见 [连接管理](#2-连接管理)）。
3. 双击或右键 → **连接** 即可打开终端会话。

---

## 2. 连接管理

### 新建 / 编辑连接

点击侧栏 **+ 新建连接**，在弹出的对话框中填写：

- **名称**：显示在连接列表中的标签。
- **主机 / 端口 / 用户名**：连接目标。端口默认 22。
- **认证方式**：`密码` 或 `私钥`。
  - 私钥：点击 **浏览** 选择本地私钥文件，可选填 **密钥口令**。
  - 密码：可勾选 **显示/隐藏密码**。
- **启动目录**：可选，如 `/var/www`，连接后自动 `cd` 进入该目录。
- **分组**：可选择已有分组，或选 **+ 新建分组…** 创建新分组；也可留空归入「未分组」。
- **备注 / 描述**：可选。

### 连接列表操作

- **连接**：双击连接，或右键 → **连接**。
- **分栏打开**：右键 → **右侧拆分** / **下方拆分**，在新分栏中打开该连接的终端。
- **编辑 / 删除**：右键对应项。删除会弹出应用内确认框（不使用浏览器 `confirm`）。
- **分组管理**：分组支持拖拽排序、重命名、删除；删除分组时其下连接自动移入「未分组」。
- **拖拽排序**：在列表中拖动连接调整顺序或跨分组移动。

## 3. SSH 终端

### 多标签

每个连接打开为一个独立标签，基于 xterm.js 渲染（`xterm-256color` PTY）。可同时打开多个标签自由切换。

### 认证

支持密码认证与 SSH 密钥认证。

### 连接状态指示

每个标签带状态点，由 SSH 层保活驱动：

- 🟢 绿色：连接正常。
- 🟡 黄色（suspect）：保活探测失败，连接疑似中断。
- 🔴 红色（closed）：重试次数耗尽，连接已断开。

保活间隔与最大重试次数可在 **设置 → 通用** 中配置（间隔最小 10 秒，重试最小 2 次）。

### 重连

连接断开后，点击标签右上角 **重新连接** 按钮可复用同一标签实例重连，无需新建标签。

### 工作目录同步

当你在终端里输入 `cd` 切换目录时，SFTP 文件面板会自动跟随同步（后台通过一次性 exec 通道执行 `pwd` 探测）。这样终端与文件浏览始终保持在同一目录。

### 终端右键菜单

在终端中右键可：

- **复制 / 粘贴**。
- **询问 AI（选中文本）**：将选中的文本作为上下文发给 AI 助手。
- **添加到命令列表**：把选中的命令存入命令片段浮动列表。

## 4. Telnet

- 通过纯 TCP 连接（`connect_telnet`），内置轻量 IAC 协商（ECHO / SGA / TERMINAL-TYPE / NAWS）。
- 窗口尺寸变化会通过 NAWS 子选项上报给服务端（Telnet 没有 PTY）。
- **自动登录**：可选匹配 `login:` / `Password:` 提示符自动填入凭据。**默认关闭**——因为 Telnet 明文传输，不建议在不安全网络使用。

> 提示：如需加密，请使用 SSH 而非 Telnet。

---

## 5. 串口（COM）

### 端口选择

- 自动枚举可用串口并显示友好名称（USB 厂商 / 产品名、VID:PID）。
- 可从下拉列表选择，也可手动输入自定义端口名。

### 串口参数

可配置：波特率、数据位、停止位、校验位、流控。波特率也可从常用值下拉框中快速选取。

### 波特率自动检测

UART 没有时钟线也没有协商机制，无法直接读取对端真实速率。本功能会：

1. 逐个探测常用波特率。
2. 对静默设备发送换行试探。
3. 对收到的字节「像不像终端文本」打分。
4. 按置信度排序返回候选结果，并附带样本预览，供你确认。

## 6. SSH 隧道

为连接保存本地端口转发规则，并在侧栏集中管理。

### 增删改

在连接列表中找到隧道入口，可 **添加 / 编辑 / 删除** 隧道。每条规则包含：

- **本地端口**：本机监听端口。
- **远程主机 / 远程端口**：经 SSH 转发到达的目标。

每条规则显示其本地地址与远端目标，转发进行中会被标记为活动状态。

### 启停

- **启动 / 停止**：在侧栏点击对应按钮。
- 隧道启动、停止或异常退出时侧栏自动同步（即使标签已断开）。

### 常见故障

若提示「服务器禁止 TCP 转发」，请检查服务器 `sshd_config`：

1. `AllowTcpForwarding yes`（或 `local`）。
2. 若配置了 `PermitOpen`，需包含目标 `host:port`。
3. `systemctl restart sshd` 后重新启动隧道。

## 7. 本地终端

可在本机打开 Shell，与远程标签并排使用。

### 添加本地终端

侧栏 **本地** 区域点击 **+**，填写：

- **名称**（可选，留空则用目录名）。
- **目录**：选择一个本地目录作为启动路径。
- **终端类型**：可选
  - 命令提示符（cmd）
  - PowerShell（pwsh）
  - PowerShell（powershell）
  - Bash
  - WSL
  - Git Bash

### 本地终端操作

- **打开**：双击条目以顶层标签打开，或在某工作区内作为分栏打开。
- **在文件管理器中打开**：右键本地终端条目，在系统文件管理器中打开其目录（跟随终端实时 `cd` 的目录）。
- **复制标签页**：右键分栏标签可克隆为新的分栏。
- **最近目录**：本地终端会记录最近访问的目录，便于快速跳转；可清空历史或移除单条。

> 在 Windows 上，本地文件浏览的根目录映射到当前盘符的根。

## 8. SFTP 文件管理

侧栏 **文件** 面板提供远程文件树浏览与操作。

### 浏览

- 文件树展开 / 折叠，支持 **上级 / 主目录 / 根目录** 快速跳转。
- **跳转到…**：输入路径直接跳转；下拉中还提供本地盘符等常用位置。
- **将当前目录设为根**：把当前目录虚拟为根，便于聚焦工作区。
- **将当前目录设为 SSH 启动目录**：把当前路径写回该连接的启动目录。
- **终端同步**：可启用/禁用「`cd` 终端 ↔ 文件」同步。

### 文件操作

- 新建文件 / 新建文件夹、重命名、删除。
- **上传 / 下载**：支持单文件与整文件夹；支持**暂停 / 继续**与进度显示。
- **拖拽上传**：将本地文件或文件夹拖入面板即可上传。
- **剪贴板粘贴**：从剪贴板粘贴文件；跨目录复制/粘贴时遇重名会提示冲突。
- **新建对话框**：创建文件/文件夹使用应用内对话框，而非系统原生输入框。

### 传输管理

- 传输列表显示进行中与已完成的传输，支持 **取消传输**。
- 删除大量文件时显示删除进度（已删除 N / M）。

### 切换 SFTP 用户

- **切换 SFTP 用户**：以其他账号身份操作文件（`switch_sftp_user`）。
- **恢复原始用户**：切回原账号。

### 跳板 / Docker 场景

文件面板还支持在以下场景中浏览文件：

- **本地 SSH 会话**
- **跳板（ProxyJump）**：经由本机连到远端。
- **Docker 容器**：在容器的文件系统中浏览。

## 9. 远程文件编辑器

- 基于 Monaco 的内联编辑器，以分栏面板或浮动窗口形式打开远程文件。
- **编码自动检测**：UTF-8 → GBK（非 UTF-8 文件会被标记，须以相同字符集重新保存）。
- **未保存提示**：关闭有改动的编辑器时会询问 **保存并关闭** / **不保存**。
- **语言选择**：可手动指定语言高亮（选项按字母排序）。
- 可在设置中配置 **可打开文件最大大小（MB）**，超限文件无法在内置编辑器打开。

## 10. Hex 与图片查看

- **十六进制查看**：在编辑器中打开的二进制文件以 hex dump 形式查看。
- **图片预览**：图片文件支持内联预览（后端自动探测 MIME 类型）。

## 11. 分栏与浮动窗口

### 分栏布局

终端区为分栏树布局：标签可 **水平 / 垂直** 拆分，每个叶节点显示终端、Docker 日志或已打开的文件编辑器。

### 浮动窗口

- 任意面板可 **弹出** 为独立浮动窗口。
  - 终端浮动：从分栏树摘下该叶节点（会话保持存活）。
  - 文件编辑器 / Docker 日志浮动：以覆盖层形式渲染在原 Shell 之上，关闭浮动时恢复原视图。
- 浮动窗口支持 **停靠**（左/右/上/下）与 **关闭**。

### 按会话隔离

每个标签的打开文件与 Docker 日志相互隔离——在 A 会话打开的文件不会出现在 B 会话。

### 复制标签页

右键分栏标签 → **复制标签页**，克隆为新的分栏（支持 SSH 会话、本地 Shell、Docker 终端会话）。

## 12. 会话录制

### 开启

- 默认 **自动录制**（连接 SSH 后即开始）。可在 **设置** 关闭自动录制，或在每个面板用录制按钮手动控制。
- 也可用环境变量 `WROLP_RECORDING=0`（或 `false`）全局关闭。

### 内容

- 事件先缓存于内存，每 5 秒及断开时刷入 SQLite。
- 两类事件：`input`（原始按键）、`command`（回车时捕获的完整命令行，保留 Tab 补全文本）。

### 回放与管理

底部 **录制** 面板：

- 列出所有会话录制（按连接分组，显示会话数）。
- **回放**：可在回放区观看，支持 **单步前进 / 单步后退**、**结束**。
- **提取命令**：从一段录制中提取命令行。
- **删除**：单条删除或 **删除所有会话**（不可撤销）。

## 13. 命令集

保存可复用的命令组，可选绑定到某个连接，存于 SQLite。

### 新建 / 编辑

底部 **命令集** 面板：

- **名称**：如「服务器健康检查」。
- **连接（可选）**：留空则为「通用」，对所有连接可见。
- **命令**：每行一条，如：
  ```
  ls -la
  df -h
  free -m
  ```

### 执行

- **在活动终端中执行**：将命令集逐条发送到当前终端（需先连接）。

## 14. 命令片段浮动列表

一个可浮动的命令片段面板，用于保存常用单条命令并快速发送到终端。

### 添加

- 在终端或 AI 对话框中选中文本 → 右键 **添加到命令列表**。
- 也可在面板内点 **添加命令** 手动录入，支持 **别名**（如「检查磁盘占用」对应 `df -h`）。

### 查找与组织

- **搜索**：按关键字过滤。
- **仅显示常用**：只看收藏项。
- **显示已隐藏**：查看被隐藏的片段。
- 每条可 **设为/取消常用**、**隐藏/取消隐藏**、**删除**。

### 变量

- 命令中可写变量，如 `ssh {user}@{host}`。
- 发送前会弹出 **填写变量** 对话框，让你填入当前值。
- **变量管理器**：定义全局变量（名称、默认值、描述），在不同片段间复用。变量名须以字母或下划线开头，只含字母数字下划线。

### 发送

- 点击命令片段即发送到终端（按回车执行）。
- 面板透明度可调。

## 15. Docker 容器与日志

侧栏 / 底部 **Docker** 面板（需先连接到一台装有 Docker 的服务器）。

### 容器列表

- 默认只显示运行中的容器；勾选 **全部** 可显示已停止的容器。
- 每个容器可：**启动 / 停止 / 重启 / 删除**（删除仅对已停止容器，不可恢复）。
- 操作后容器列表自动刷新。

### 分析容器

右键运行中的容器 → **分析容器**，查看：

- 概览（镜像、命令、Compose 项目/服务/配置/工作目录等）。
- 端口、挂载、环境变量、进程列表（PID / CPU% / MEM% / 命令）。
- 资源占用（CPU、内存、网络 IO、块 IO、进程数）。

### 查看日志

- **查看日志**：流式获取容器日志，支持 **自动换行 / 跟随最新 / 尾部 N 行 / 刷新**。
- 日志可作为一个独立 **日志标签** 打开，并可 **弹出** 为浮动窗口。
- 重连后自动重新发送原 `docker exec` 等命令，保持面板一致。

### 进入 Shell

右键容器 → **进入 Shell**，获得该容器的交互终端。

## 16. 主机分析

底部 **分析** 面板（需先连接主机）。

### 分析主机

点击 **分析主机**，得到只读概览：

- 操作系统、内核、架构、主机名、包管理器。
- 检测到的常用工具（数量与列表）。

## 17. AI 助手

顶部 **AI 对话** 按钮或标签打开。两种模式：

- **对话**：非流式问答。
- **智能体（Agent）**：流式 + 工具调用，可在已连接的服务器上执行只读/受限操作。

### 配置（设置 → AI）

- 可保存多个 **端点**（`AiEndpointProfile`），各自拥有：API Key、基础地址（Base URL）、模型、系统提示词。
- 选择一个为 **活动端点**。
- **获取模型**：从 `{endpoint}/v1/models` 拉取模型列表填充下拉框；也支持手动输入模型名。
- API Key 通过 AES-256-GCM 文件保险库加密存储（机器专属 `vault.key`，不使用系统密钥环）。

### 使用

- **多模态**：可在消息中附加图片，让模型理解截图/示意图。
- **模板**：内置分类模板（问题排查 / 安全加固 / 备份与定时 / 性能与网络），并可添加自定义模板（含类别、隐藏/恢复）。
- **编辑并重发**：可编辑任意历史消息后重新运行。
- **暂停**：用 **停止** 中止正在进行的生成，可从中断处继续。
- **发送到终端**：助手消息中的 Bash 代码块可一键 **复制**，或直接 **发送到终端** 执行。
- **工具卡片**：工具调用归组在对应助手消息下，状态为 `pending → executing → done/error`，可展开查看参数与结果。
- **敏感命令确认**：破坏性命令会弹窗询问 **允许 / 拒绝** 后才执行。

### 行为开关

- **只读模式**：开启后 AI 默认只运行查看类命令（状态、日志、读文件），修改类命令被阻止。可在面板顶部切换「只读 / 可写」。
- **在终端中执行**：开启后 AI 的命令像你手动输入一样打进当前终端（可见、计入录制、共享工作目录/环境/sudo）。关闭则后台静默执行（有退出码但不可见）。无活动终端时自动回退为静默执行。
- **最大轮数**：限制一次 Agent 循环内「助手回复 + 工具调用」的最大轮数（默认 200，0 为不限制），防止死循环。

### 与终端联动

- 终端中选中文本 → 右键 **询问 AI（选中文本）**，作为上下文发送。
- Docker 日志可 **询问 AI（全部日志）** 或（选中文本）。

> 未配置 AI 端点时会提示先去设置中配置。

## 18. 网络扫描

侧栏连接列表上方 **扫描网络** 按钮打开对话框，用于发现网段内开放的 SSH/Telnet 服务并一键添加为连接。

### 填写

- **扫描目标**：支持
  - CIDR：`192.168.1.0/24`
  - 单 IP：`10.0.0.5`
  - 末段区间：`192.168.1.10-192.168.1.20`
- **端口**：逗号分隔，如 `22,2222`。
- **分组（可选）**：扫描到的连接归入哪个分组（可新建）。
- **高级**：超时（毫秒）、并发数。

### 扫描

- 点击 **开始扫描**，进度条显示「已探测 N/M」。

## 21. 数据与安全

### 存储位置

所有数据存放在操作系统配置目录下的 `wrolp-terminal/`：

- `window.json`：窗口几何、透明度、录制与保活设置。
- `connections.json`：连接与工作区配置（**已加密**）。
- `wrolp.db`：SQLite（WAL 模式），存会话录制与命令集。
- `vault.key`：机器专属的加密密钥文件。

### 加密

- 连接配置与 AI API Key 均通过 **AES-256-GCM** 文件保险库加密存储，**不使用操作系统密钥环**。
- 因此 `vault.key` 是解密关键——迁移或备份时请同时保管该文件；丢失后将无法解密既有凭据。

### 录制与隐私

- 会话录制默认开启，记录你的按键与命令。如不希望记录，请在设置关闭「自动录制会话」，或使用环境变量 `WROLP_RECORDING=0` 全局关闭。
- 录制数据保存在本机 SQLite，不上传任何远端。
